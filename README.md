# Shoaib Asghar — Portfolio

A modern, responsive single-page portfolio showcasing my skills, projects, and experience in AI, Machine Learning, and Full Stack Development.

Built with pure HTML, CSS, and JavaScript, making it lightweight, fast, and easy to deploy without any build tools or dependencies.

## Features

- Responsive design for desktop, tablet, and mobile
- Light/Dark theme
- Smooth scrolling and section animations
- Interactive skills section
- Project showcase
- Downloadable resume
- Contact form
- Clean and modern UI

## Design

- **Background:** Ink Navy (`#0B0F17`)
- **Accent Colors:** Copper (`#E28D4F`) and Teal (`#52C7B8`)
- **Fonts:**
  - Space Grotesk
  - Inter
  - JetBrains Mono

The design is inspired by my Fuel Route Optimizer project, using animated route-line elements throughout the website to create a unique visual identity.

## Running Locally

Simply open `index.html` in your browser.

Or run a local server:

```bash
python3 -m http.server 8000
```

Then visit:

```
http://localhost:8000
```

## Deployment

This is a static website and can be deployed on platforms like:

- Vercel
- GitHub Pages
- Netlify
- Cloudflare Pages

No build process is required.

## Customization

All content is contained inside `index.html`.

You can easily update:

- About section
- Skills
- Experience
- Projects
- Resume
- Contact information
- Theme colors
- Animations
